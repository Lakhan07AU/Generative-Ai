## Contents

### Assignments

The `Assignment` folder contains course assignments and notebooks.

#### Assignment 1 — Understanding Generative and Discriminative Models Using MNIST

The first assignment uses the MNIST dataset and focuses on handwritten digits **0 and 1** to demonstrate the difference between discriminative and generative learning.

**Discriminative model:**
- Logistic Regression
- Binary classification of digits 0 and 1
- Accuracy evaluation
- Visual prediction results

**Generative model:**
- Basic Autoencoder
- Image reconstruction
- Latent representation learning
- Generation of new digit-like images
- Visual comparison of real, predicted, reconstructed, and generated images

Notebook: [`Assignment/MNIST(Assignment1).ipynb`](Assignment/MNIST(Assignment1).ipynb)
